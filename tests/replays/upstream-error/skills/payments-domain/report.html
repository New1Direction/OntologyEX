Authored scope and boundaries

# Scope

Fictional, single-currency partial refunds and unresolved exception approval.
Consumer: local domain skill and in-memory fixture only.
Questions: what can be refunded, how much remains, who may approve an exception, which code changes the ledger?
Out of scope: real APIs, concurrency, currency conversion, identity verification, production authorization.

What the business means

ConceptDefinitionEvidence
PaymentPayment is a money ledger record with captured_minor, refunded_minor, and a payment_status.E-Payment
RefundRefund is a return of some captured money against one Payment.E-Refund
MonetaryAmountMonetaryAmount is an integer number of minor currency units in this single-currency fixture.E-MonetaryAmount
